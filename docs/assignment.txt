Тестовое задание: прототип узлов Knowledge Base + RAG
Цель задания
Перед началом разработки необходимо проверить понимание архитектуры проекта и подход к проектированию интерфейса для AI/SEO-платформы.
Нужно подготовить прототип двух связанных узлов:
Knowledge Base → RAG → AI Agent
Прототип можно выполнить в Moqups, Figma или другом удобном инструменте.
Нам не нужен полноценный UI-дизайн. Основная задача — показать логику системы, структуру данных, взаимодействие компонентов и пользовательский сценарий.
1. Knowledge Base
Представь, что Knowledge Base является единой базой знаний проекта TRON POOL ENERGY.
В неё поступают данные из:
сайта;
TRON Docs;
GSC;
GA4;
Ahrefs;
AI Visibility;
других внешних источников.
На первом этапе достаточно показать работу с контентом сайта.
Необходимо показать:
Список документов / статей
Для каждой статьи желательно отображать:
название;
источник;
язык;
статус;
дату обновления;
количество chunks;
наличие embeddings;
версию.
Например:
USDT TRC-20 Transaction Fees
Source: TRON POOL ENERGY
Language: EN
Status: Processed
Chunks: 48
Embeddings: 48
Version: 1.2

6. Context Builder
Это важная часть задания.
Покажи, что RAG не передаёт AI всю Knowledge Base.
RAG выбирает только релевантную информацию и формирует компактный контекст.
Например:
User Question
↓
RAG Search
↓
Top relevant chunks
↓
Relevant Facts
↓
Sources
↓
Verification status
↓
Context Builder
↓
AI Agent
На экране желательно показать:
Retrieved Context
Какие именно chunks были выбраны.
Sources
Откуда они получены.
Facts
Какие факты были использованы.
Confidence
Насколько система уверена в найденной информации.

Важно показать понимание принципа:
RAG использует Knowledge Base, но Knowledge Base и RAG — не одно и то же.
Knowledge Base отвечает за хранение и структурирование знаний.
RAG отвечает за поиск релевантных знаний и формирование контекста для AI.
