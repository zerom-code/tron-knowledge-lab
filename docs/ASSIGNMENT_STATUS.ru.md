# Соответствие тестовому заданию

Версия 3.1.0. [Исходные условия](assignment.txt).

| Пункт | Реализация |
|---|---|
| 1. Knowledge Base | Документы и metadata в PostgreSQL; список и статусы |
| 2. Структура документа | Version → Section → Chunk; Fact/Claim → Evidence → Source; entities/topics |
| 3. Обработка | Worker, постоянная очередь, этапы, Failed, retry и история версий |
| 4. RAG Search | Правила понимания запроса; SQL prefilters; pgvector + FTS → RRF → reranker |
| 5. Результаты | Chunk, источник, relevance, язык, дата, verification, документ и ранги |
| 6. Context Builder | Выбранные chunks/facts/sources; лимиты контекста и достаточность evidence |
| 7. AI Agent | Async OpenAI; ответ по контексту; цитаты и проверка каждого абзаца |
| 8. Low Confidence | Блокировка генерации, причины отказа и действия пользователя |
| 9. Metadata | Language/source/topic/entity/document/date/verification для обоих поисковых путей |
| 10. Архитектура | [Схема](../static/architecture.md), словарь, решения и вопросы для обсуждения |

Шесть экранов находятся в одном приложении. Снимки и результаты проверок —
в `verification/`. Приложение запускается через Docker Compose; база сохраняется
в volume. Публичный адрес не входит в поставку.

## Границы

ТЗ разрешает прототип в Figma/Moqups или другом инструменте. Эта реализация
содержит работающий Python backend и БД. Она показывает один сценарий,
описанный в тестовом, и не реализует целиком проект V1.

Четыре начальных документа образуют ограниченный корпус. Источники и
embeddings сохранены; Saved использует ранее полученные оценки и ответы
OpenAI, Live получает новые. Новые документы требуют отдельной сверки.

Query understanding и entities основаны на правилах; извлекаемые claims —
выдержки-кандидаты. Универсального извлечения атомарных фактов моделью,
автоматической проверки истинности и разрешения конфликтов нет.
Порог confidence является демонстрационной политикой, а не измеренной
точностью системы. Проверка ответа моделью может ошибаться.

Поддерживается один проект с паролем редактора. Полный RBAC, multitenancy,
GSC/GA4/Ahrefs, Wagtail publication, crawler и все агенты V1 не реализованы.
